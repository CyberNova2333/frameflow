## 剩余风险与未覆盖边界

- **硬件 GPU 实测与文档生成分离**：本轮重点同步源码指南与建立文档站，未重跑真实 Vulkan/Intel Xe-LPG 无头浏览器数值对齐与模型重训；既有基准数据援引自既有验收记录。
- **跨仓库外部集成**：PVSSPW 与 PPSSPW 的外层壳页面与调度细节需参考各自仓库及集成说明，本包只锁定从设备或上下文共享接口进入之后的运行时行为。
- **权重包在线托管**：由于二进制模型不随源码库提交，实际部署时若路径缺失或 CORS 配置缺失，会在资源拉取阶段而非模型编译阶段阻断加载。

## 反证条件与读者下一问

- **反证检查**：如果发现在不支持半浮点渲染目标的环境下运行时仍然返回成功并开启 CPU 计算，或发现不经 `parseModel` 校验版本号的旧格式图结构能分配显存，则说明本文档关于能力门禁与静态格式约束的结论已经过时。
- **读者下一问**：在不改动算子实现的前提下单独训练并替换新版模型权重包时，应更新哪些文件与校验环节？通常按[训练与发版模块](../modules/training-and-release-pipeline.md)打包三文件产物后替换静态挂载目录，并对照[源码证据](source-evidence.md)重新运行节点测试与双后端数值校验。
